Title
PermitDecisionTree - Forward-Only Authority Routing Tree

Notes / Description
Built PermitDecisionTree, a reusable forward-only authority tree where validators answer one frozen project question per step, code follows the branch, and only the publishing authority can resolve an unclear node. Its distinct GenLayer-native mechanism is validated acyclic binary tree -> evidence-bounded one-node consensus -> deterministic traversal -> authority uncertainty lane. Correction applied: Each model answer is canonicalized against the exact answer set of the active frozen node both inside the validator and after consensus, so a shape-valid but node-invalid answer cannot advance the tree. The full selected set was checked against both steward findings: substantive leader payloads must bind every derived digest, mask, and state field, while operational registries must be owner-scoped or safely reclaimable. No live collection. Guidance trees, project descriptions, and source references are public caller-supplied snapshots and are not authenticated. It is an informational router, not a permit, code-compliance finding, government decision, or professional advice. GenVM lint and strict typecheck pass; 11 direct tests and 1 five-validator GLSim integration test pass. A fresh repository-specific external wallet set was used, with no workspace, other-owner, or cross-repository wallet reuse. The StudioNet workflow finalized successfully in 4 transactions. The deployed source was read back byte-for-byte, the complete deployed schema matched abi.json exactly, and mechanism-specific terminal state was read back. The current release is commit 459aa5f3fc9e7bb6d627f1e32205b454c6ab9ac2; contract source: https://github.com/sanity456/permitpath/blob/459aa5f3fc9e7bb6d627f1e32205b454c6ab9ac2/contracts/permit_decision_tree.py.
